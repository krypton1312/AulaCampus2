# JetShark
Sitio web estático para **venta y reserva de motos de agua** con visor 3D.

## Paleta
- Fondo principal: #D0EFEF
- Fondo secundario: #AEE3E0
- Acento: #5DA98B

## Cómo usar
1. Abre `index.html` en tu navegador.
2. Coloca tus modelos 3D (`.glb/.gltf`) en `assets/models/` y cambia la ruta en el `<model-viewer>`.
3. Edita los datos de `modelos.html` en el array `data` para tus modelos reales.
4. Personaliza colores y estilos en `css/style.css`.

## 3D
Este proyecto usa `<model-viewer>` desde CDN para visualizar archivos `.glb/.gltf` (https://modelviewer.dev).

## Hosting
Puedes subir la carpeta a Netlify, Vercel o GitHub Pages.
